# Security Policy

Roomsmith is a local macOS app. Its optional agent API listens only on the local machine and is meant to be used by
tools you run yourself.

## Reporting a vulnerability

Please report security problems privately through GitHub: **Security → Report a vulnerability** on this repository.
Do not open a public issue for them. Include the Roomsmith version (see `VERSION`), your macOS version and the steps to
reproduce the problem.

Roomsmith is maintained by one person in spare time; expect an answer within a few days, not hours.

## Supported versions

Only the latest release receives fixes.

# Test Matrix

Acceptance tests for Roomsmith. Status values: `covered` (an automated test checks the requirement), `partial` (a test checks part of it; the reason is given), `manual` (only checkable by hand), `pending` (nothing exists), `failing`. Location is `File.swift: testName` under `Tests/RoomsmithCoreTests/`. `covered` means the test exists and checks the requirement; whether it passes is shown by `scripts/check.sh`, not by this table. Test targets: `RoomsmithCoreTests` (core, no GUI) and `RoomsmithAppTests` (hosted app-side checks of `Sources/Roomsmith`: drag, drop, Esc, Delete key (DeleteKeyTests.swift), Hand tool (HandToolTests.swift), mesh tint; needs a GUI session, about 20 s). The rest of the app side (3D rendering, gizmo, picking, animation) is not covered by automated tests.
